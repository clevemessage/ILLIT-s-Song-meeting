# 礼国猜歌会 Demo

一个可直接公开访问的静态网页游戏 Demo，内容来自线上版本 `https://liguo-listening-demo.vercel.app/`，并已整理为 GitHub Pages / Netlify 都能发布的静态站点。

## Public Access

GitHub Pages:

```text
https://clevemessage.github.io/ILLIT-s-Song-meeting/
```

## Netlify Optional

- Build command: leave empty
- Publish directory: `.`

This project is a plain static site: `index.html`, `styles.css`, `app.js`, `audio-config.js`, `game-utils.js`, and `assets/`.

## Local Preview

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.
